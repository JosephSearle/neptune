Servers in production

Auth, tool scoping and audit logs for servers agents actually call.

By Joseph Searle

MCP

An agent should never decide what it is allowed to do. Put the scope check in the server, next to the tool, and log every call.

[ Tip ]

Start every server read-only. Add write tools one at a time, each behind its own scope.

What to log

Who called, with which token. Which tool, with which arguments. What came back, and how long it took.
