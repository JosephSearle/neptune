# Switch

An on/off control for a setting that applies at once. Square track, square thumb; on fills `neptune`.

- Markup: `<label class="np-switch"><input type="checkbox" role="switch"> Label</label>`.
- The label names the setting, not the state: "Compact tables", not "Turn on compact tables".
- Use for settings that take effect immediately. For choices submitted with a form, use a Checkbox.
- Disabled: add `disabled` to the input.
- Don't: pair a switch with a Save button.
