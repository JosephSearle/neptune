# Kbd

A physical-looking key for shortcuts, with a 2px bottom edge.

- Markup: `<kbd class="np-kbd">K</kbd>`. One key per element; chords are adjacent keys separated by a space.
- Consumer provides: the key name. Use symbols for modifiers: ⌘ ⇧ ⌥ ⌃.
- Show the shortcut beside the action it triggers, e.g. in the nav search button.
