# Tag

A square mono label for categories, licences and status.

- Markup: `<span class="np-tag">`. Variants: `np-tag--accent`, `np-tag--ok`, `np-tag--alert`.
- Consumer provides: 1–3 words. Separate parts with ` · `.
- Status tags (`ok`, `alert`) include `<span class="np-dot">` and a word. Never colour alone.
- One accent tag per card at most.
- Don't: round the corners, use emoji, use tags as buttons.
